EMBER & OLIVE RESTAURANT WEBSITE

This is a standard static HTML website and can be hosted on any web server.

FILES
- index.html: Home page
- menu.html: Menu page
- reservations.html: Reservations page
- styles.css: Complete website styling
- app.js: Mobile menu, scroll effects and reservation confirmation

HOW TO HOST
1. Extract this ZIP file.
2. Upload every extracted file to your hosting root folder, usually public_html.
3. Keep all files together in the same folder.
4. Open your domain. The server will load index.html automatically.

The food and restaurant photography is loaded from Unsplash, so the website
requires an internet connection to display those images.
